# Banner 实验反馈与规则状态

本文件保留用户对成图的反馈，供后续修订 Skill 或诊断重复问题时读取。它记录观察和当前工作假设，不把某张旧图变成未来任务的默认画风。新参考图由新任务提供。

| 实验中的观察 | 已纳入的工作方法 | 状态 |
| --- | --- | --- |

| 有一次画风方向对了，主标题却过小，失去视觉主导 | 375px 宽优先检查标题是否第一眼可读；长文案优先压缩或换布局 | 已确立 |
| 街机风参考实验偏离原图气质，画面元素多，背景变成单调纯色 | 以原图的设计语言建立满幅场景；背景、主体、文字共享风格，不用色块替代完整视觉创作 | 方法已确立，稳定性待验证 |

| 反复生成导致时间过长，文字方案难以评价 | 首轮三个方向直接并行生图；集中检查后只返修具体失败方向 | 已确立 |

## 仍需用后续成图验证

1. 不同参考图下，标题之外的元素能否持续产生“同一创作者”的系列感。
2. 满幅视觉与顶部、底部避让能否在生成阶段同时实现，减少后期补救。
3. 中文标题、价格与辅助文案能否稳定准确，并在 375px 宽保持可读。
4. 三方向能否在创意差异、主题色变化和风格统一之间保持平衡。

收到新反馈时，先判断它属于业务事实、风格迁移、创意密度、构图安全、技术导出或效率哪一环，再更新对应 reference。只有经过实际成图验证的修法才升级为通用规则。
