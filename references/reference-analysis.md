# 第一层：参考图分析与视觉语言迁移

适用于用户提供新的画风参考图、指出生成图“不像同一系列”，或要求比较参考图与成图时。先按用户说明给每张图标注角色；当前参考图的视觉气质优先于历史实验图。本层输出可迁移的视觉语言，Banner 的传播任务与产品约束见[第二层](banner-design.md)。

## 参考边界

- **画风参考**提供完整的视觉系统：造型、线条、材质、场景搭建、主体互动、图文嵌合及色彩关系。它的信息密度不直接决定 Banner 的目标密度；独特角色、标志和现成画面不成为新图的素材。
- **构图参考**提供标题、主体和视线的空间关系。常见的版式结构可按业务和横幅画幅重组；具有识别性的具体摆位、角色动作及道具组合须重新设计。
- **业务素材**提供事实与指定对象；无法辨认的商品细节应先核实。用户指定使用的品牌、商品或角色素材按业务要求处理，与外部画风参考分开标记。
- **原图画幅**影响原图的叙事节奏。转换为 Banner 时先确立首页一眼可读的焦点，再决定哪些视觉特征能保留。不要把竖版改横版当作全部分析。

## 产出一份简短的视觉指纹

从图中选出能形成画面关系的 **2–3 个高辨识特征**，用可画出来的语言描述，避免只写“复古、可爱、高级”等情绪词，也避免把某个独特角色或标志当成风格特征。优先让主体画法与材质或空间关系同源；配色与标题字形不能单独充当视觉指纹。分析时可以观察更多维度，单次生图输入只保留足以建立参考气质的少数特征，避免把参考的整套复杂场景搬进 Banner。

| 观察项 | 应看什么 | 转译到 Banner 的位置 |
| --- | --- | --- |
| 字体 | 字重、字宽、笔画末端、手写不规则性、描边、投影、字距、行间关系 | 主标题和少量辅助字；保留汉字可辨认性 |
| 轮廓与造型 | 线条粗细变化、端点、转角、比例、五官、物体简化方法 | 商品、角色、符号及装饰共享一套画法 |
| 填色与材质 | 实色、错位套印、网点、纸纹、颗粒、笔触边缘、阴影 | 标题、主体、背景采用一致的材质逻辑 |
| 颜色关系 | 主色/陪衬色的面积、明度、冷暖、局部撞色、黑白使用 | 与选定 C 色号协调，保留原图的关系而非机械取色 |
| 空间与节奏 | 平面/透视、重叠、疏密、视觉流向、留白位置 | 为 App Banner 重新组织视线路径 |
| 场景与互动 | 主体处在什么环境，人物、商品和道具如何发生关系，哪些层次让画面完整 | 用新业务主体重建同等丰富度的叙事关系 |

观察参考的标题是否通过局部变色、放大数字、异形描边、笔画连接或材质变化突出一个关键词。把这类**字内层级**转译到新文案的对应重点上，例如在「朋友享9折」里突出「9」；它仍是一句文案，不额外生成第二个折扣牌。保留字形辨识度和所选布局的安全边界。

当参考的辨识度主要来自 3D 表现时，把“立体”展开为可观察的材料、厚度、接触阴影和光源关系，并让标题、主体与场景共享这套空间逻辑；仅添加投影仍可能停留在平面表现。毛绒、黏土、纸塑等材料由本次参考决定。群像或堆叠参考另说明主陪体的数量、相对尺度及用途，避免为借鉴画风增加无关设备、结果卡或角色。AI娘案例支持这些判断，跨任务效果仍待验证。

单独说明参考如何通过包围、承托、斜向流动、前后层次或图文嵌合组织空间，并选择适合新业务及横幅边界的关系。替换具体主体后，检查这种空间方法是否仍体现在画面中。

同时写出 **不迁移项**：原图的具体文案、人物或商品身份、角色轮廓与五官组合、服装和配饰识别点、标志、具有识别性的道具组合、画幅独有的长观看路径、信息块数量、未经业务证实的促销说法。参考图中的对象若与当前业务无关，由新的业务主体替换；场景的搭建方式和元素之间的关系仍可转译。

## 有主视觉 IP 时的替换判断

遇到参考图以独特角色或品牌形象为视觉核心，先判断当前业务是否需要角色。需要时，另定角色的身份、轮廓、五官、服饰和标志性配色，再用参考中的线条力度、简化方式、材质和场景组织方法绘制**原创角色**；业务适合由商品、符号或场景说明时，也让替换主体拥有同等的形态设计和互动关系。保留画面的表现力与完成度，同时重新设计可识别的角色、标志、姿态及道具组合。若用户要求原样使用外部角色或标志，先核实其是否属于本次可用的业务素材。

不要把“有 IP 风险”解释为“删除角色、故事和场景”。在带角色的手绘参考中，只留下底色、纹理和泡泡字，再放一件空白商品，会失去视觉语言的主要载体。可重新设计一个与当前业务有关的角色或商品场景，继续使用参考的粗线、比例夸张、手工边缘、前后层次及互动节奏。

## 迁移与系列感检查

构思完后，把视觉指纹逐一映射到四处：**主标题、核心主体、场景背景、少量点缀**。只有标题共享视觉方法，主体却是通用素材或另一种插画语言时，系列感仍不成立。一个新增元素需要能回答：它怎样使用提炼出的线条、材质、空间和互动规则，同时保持自己的造型？

首轮再做一项“遮色比较”：暂时忽略两图的颜色和文字，查看主体造型、物件关系、材质、空间层次是否仍能看出相近的画面语言。若看不出来，说明只借到了表层配色与字体；若能直接认出参考的独特角色或具体场景，说明替换不足。

对照原图与 Banner 的缩略图，再检查局部细节：线条是否同种力度；形状是否同种简化；材质是否同一逻辑；配色是否同一种关系。随后反向检查新图的角色轮廓、五官、服饰、标志、姿态和道具组合是否仍能让人认出原图主体；若是，重新设计该主体或替换表达。新图应靠视觉方法建立系列感。

以上分析可以在内部完成。用户要求直接看图时，直接进入成图阶段；方向数量以用户指定为准，未指定时默认三个。交付说明只写能够帮助比较的差异。
