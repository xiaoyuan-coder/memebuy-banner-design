# 参考图分析与视觉语言迁移

适用于用户提供新的画风参考图、指出生成图“不像同一系列”，或要求比较参考图与成图时。构图教程图、Banner 案例集和业务素材各有独立用途；先按用户说明给每张图标注角色。当前参考图的视觉气质优先于历史实验图。

## 产出一份简短的视觉指纹

从图中选出最能识别作者的 **3–5 个特征**，用可画出来的语言描述，避免只写“复古、可爱、高级”等情绪词。

| 观察项 | 应看什么 | 转译到 Banner 的位置 |
| --- | --- | --- |
| 字体 | 字重、字宽、笔画末端、手写不规则性、描边、投影、字距、行间关系 | 主标题和少量辅助字；保留汉字可辨认性 |
| 轮廓与造型 | 线条粗细变化、端点、转角、比例、五官、物体简化方法 | 商品、角色、符号及装饰共享一套画法 |
| 填色与材质 | 实色、错位套印、网点、纸纹、颗粒、笔触边缘、阴影 | 标题、主体、背景采用一致的材质逻辑 |
| 颜色关系 | 主色/陪衬色的面积、明度、冷暖、局部撞色、黑白使用 | 与选定 C 色号协调，保留原图的关系而非机械取色 |
| 空间与节奏 | 平面/透视、重叠、疏密、视觉流向、留白位置 | 为 App Banner 重新组织视线路径 |

同时写出 **不迁移项**：原图的具体文案、人物或商品身份、偶然道具、画幅独有的长观看路径、信息块数量、未经业务证实的促销说法。参考图是画风来源；其元素只有在能表达当前业务且符合风格时才进入新图。

## “同一创作者”检查

构思完后，把视觉指纹逐一映射到四处：**主标题、核心主体、背景、少量点缀**。只有标题像参考图，主体却是通用素材或另一种插画语言时，系列感仍不成立。一个新增元素需要能回答：它在参考图的造型规则下会如何被画出来？

对照原图与 Banner 的缩略图，再检查局部细节：线条是否同种力度；形状是否同种简化；材质是否同一逻辑；配色是否同一种关系。允许新用途带来新构图和新内容。若只靠主题色或贴几个相同道具才显得相似，重新提炼视觉指纹。

## 参考边界

- **画风参考**提供视觉语法与审美气质；它的信息密度不构成 Banner 的目标密度。
- **构图参考**提供标题、主体和视线的空间关系；其画风、商品和文案不进入结果。
- **业务素材**提供事实与指定对象；无法辨认的商品细节应先核实。
- **原图画幅**影响原图的叙事节奏。转换为 Banner 时先确立首页一眼可读的焦点，再决定哪些视觉特征能保留。不要把竖版改横版当作全部分析。

以上分析可以在内部完成。用户要求直接看图时，直接进入三个成图方向；交付说明只写能够帮助比较的差异。
