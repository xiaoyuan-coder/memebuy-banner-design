# Memebuy 首页 Banner 制作规范要点

来源：用户提供的《Banner 规范》v1.2（2026-10-08）。[原始规范全文及四张示意图](source/Banner%20规范.md)已随 Skill 归档；本文件是执行索引。后续若用户提供新版规范，以新版为准。

## 静态文件与同源裁切

- App 主稿：1440×960 px，3:2，不透明 PNG，背景铺满四边。
- Web：从 App 主稿精确裁取全宽 `y=144..863`，得到 1440×720 px，2:1；像素须与原图对应区域一致。若裁切损失关键内容，调整 App 主稿后重新导出。
- 两端不拉伸、不独立生成 Web 图。素材不烘焙手机框、状态栏、页面按钮、轮播点、辅助线或页面遮罩。

## App 安全区

坐标原点在左上，x 向右、y 向下；右／下界不包含。

| 区域 | 范围 | 可承载内容 |
| --- | --- | --- |
| 顶部避让 | 全宽 y=0–208 | 延续背景、非关键装饰；避开重要文字和面部。 |
| 核心构图 | x=70–1370，y=208–800 | 主要文字、主体面部和商品关键细节；无需撑满。 |
| 底部避让 | 全宽 y=806–960 | 背景、低细节纹理、非关键装饰。 |
| 过渡余量 | y=800–806 | 不放关键内容。 |

安全区约束关键内容的位置与完整性，不要求留白。完整文字及其描边阴影、人物面部和商品关键细节都守住边界。Web 裁切后的核心映射为 x=70–1370、y=64–656。

## 标题位置

每稿选一种，范围包含描边和阴影；避免压住面部、眼睛和商品印花。

- 左：x=105–725，y=253–725；主体在右。
- 右：x=715–1335，y=253–725；主体在左。
- 居中：x=160–1280，y=300–620。
- 居中偏下：x=160–1280，y=480–725。

## 实际尺寸与页面

- 在 375×250 px、100% 页面缩放下检查。主标题建议至少 24px（1440px 原稿约 93px），常用起点 32px（约 123px）；辅助文字建议至少 15px（原稿约 58px）。更窄显示宽度按 `原稿字号 ≥ 向上取整(目标显示字号 × 1440 ÷ 实际显示宽度)` 重算。生成图不能仅凭提示词证明字号达标；细体、镂空及复杂纹理需特别检查。
- 主标题建议最多两行。文字放不下时先精简文案或换布局。
- V2.1 首页基础遮罩在高度 0%–78% 透明，86% 为 12% 不透明度，94% 为 42%，98% 为 78%，底部为 100%。渐变从 App y=748.8 附近开始加强。它不改变核心区和底部避让；进入此区域的内容仍需放进真实页面检查。素材本身不叠加这层遮罩。
- 真实首页须检查展开、滚动过渡、吸顶和回到顶部状态；若缺少页面环境，标记此项未验收。

## 内容与交付核对

- 活动主题、文字、价格、优惠、日期、商品信息及点击去向必须准确；缺少真实资料时不得编造。
- 静态图一张即可表达主要信息。检查无错字、伪文字、遗漏、变形、白边、透明边或明显拼接。
- 每方向交付 App 与同源 Web 图、主题色编号和 HEX、布局、实际文案，并注明真实首页验收状态。
- 动态 Banner 若在任务范围内：8–12 秒 MP4、无音轨；首帧完整展示标题、主要价值与主体，播放一次后页面切换下一张。关键内容不能只在某一瞬间出现；文字持续可读，运动中的关键内容始终遵守安全区。网页自动播放可能受浏览器限制，信息不能依赖播放成功。
- 实际上线还需核对活动日期、落地页目标、素材版本以及页面主题色绑定；产品确认业务，设计检查画面，开发检查加载与绑定，测试在真实设备上验证。
