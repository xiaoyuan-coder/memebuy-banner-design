# 第二层：Memebuy 首页 Banner 制作规范

来源：用户于 2026-10-28 提供的《Banner 规范》v1.4（文档标注更新日期 2026-10-19），适用 App 首页 V2.2；主题色沿用 V2.1。[源规范文字及完整 PDF](source/Banner%20规范.md)随 Skill 归档。旧 v1.2 及旧实验坐标仅供追溯。传播任务与视觉组织见[创意与构图](banner-design.md)。

源规范允许结合整体视觉灵活判断。本 Skill 将尺寸、遮挡避让和文字完整性作为交付验收条件；字号、内部缓冲及构图配比保留建议性质。新参考的画法和构图在这些边界内安排，提示词只保留与本稿有关的约束。

## 文件规格

- App 主稿：**1440×1000 px（36:25）**，不透明 PNG，背景铺满四边。
- 默认只制作静态 App 图。用户要求 Web 时，从 App 精确裁切 `x=0、y=144、宽1440、高720`，输出 1440×720；不单独生图、重排或二次 cover。动态条款见源规范，不由本轮静态 Skill 迭代扩展制作范围。
- 旧 1440×960 稿迁移时只向底部增加 40px，新增 `y=960–1000` 仅承接背景与阴影；原有内容不缩放、不整体平移。旧图另按新顶部与标题范围复核，扩高本身不代表迁移合格。
- 素材不烘焙手机框、状态栏、首页双入口／系统按钮、轮播指示条、辅助线或页面遮罩。Banner **自身的活动 CTA 按钮**属于画面内容，按[创意与构图](banner-design.md#传播任务一眼观看路径)制作并检查安全区。

## 关键内容边界：App 安全区

坐标以 1440×1000 为准，原点在左上，x 向右、y 向下；右／下界不包含。

| 区域 | 范围 | 可承载内容 |
| --- | --- | --- |
| 顶部避让 | 全宽 y=0–256 | 连续背景、非关键装饰；避开重要文字、面部及商品关键细节。 |
| 核心构图 | x=70–1370，y=256–800 | 主要文字、活动 CTA、面部与主体关键部位；无需撑满。 |
| 过渡余量 | y=800–806 | 保留 6px，不塞关键内容。 |
| 底部内容避让 | 全宽 y=806–1000 | 背景、低细节纹理、非关键装饰。 |
| 页面按钮实际遮挡 | 全宽 y=860–1000，高140px | 检查页面叠加；核心内容下界仍为800。 |
| 新增底部背景 | 全宽 y=960–1000，高40px | 仅延续背景与阴影，不增加文案、按钮或商品细节。 |

安全区控制内容位置，上下背景仍满幅连续。完整文字及其描边、阴影、材质外沿，活动 CTA，人物面部、业务所需的身份识别点与商品关键细节都计入关键内容边界；普通衣摆、背景道具等按是否影响识别判断。关键内容留内部余量，避免生成偏差压线。顶部扩大后核心高度为544px，底部新增空间不用于向下扩展核心区。

## 标题布局与可读性

每稿选一种，范围包含描边、阴影与材质外沿；避免压住面部、眼睛和商品印花。

| 布局 | 标题范围 | 关系 |
| --- | --- | --- |
| 左 | x=105–725，y=301–725 | 主体在右，与顶部避让线间隔45px。 |
| 右 | x=715–1335，y=301–725 | 主体在左，与顶部避让线间隔45px。 |
| 居中 | x=160–1280，y=300–620 | 按文案与主体关系安排。 |
| 居中偏下 | x=160–1280，y=480–725 | 高245px，优先短文案或一行标题。 |

- 在 **375px 宽、约260.42px高、100% 页面缩放**下完整等比检查。主标题建议至少24px（原稿至少93px），常用起点32px（约123px）；辅助文字建议至少15px（原稿至少58px）。更窄显示宽度按 `原稿字号 ≥ 向上取整(目标显示字号 × 1440 ÷ 实际显示宽度)` 重算。
- 主标题建议最多两行。放不下先精简文案、改断行或换布局；避免不断缩字。字号是字体参数，生成图的可见字形高度或 OCR 框不能证明精确字号，仍需视觉检查。
- 脚本导出的375px预览因整数像素约为375×260，仅供初筛；真实页面保持约260.42px的完整等比显示。放大原图或70%模拟手机不能替代最终检查。

## 页面叠加与真实状态

- V2.2 首页完整等比显示原图；取消额外10px底边延伸，不再取最后一行像素生成延伸层，不把原图裁切或拉伸成375×260。
- 375px宽页面下，遮罩渐变起点和双主按钮顶边均在屏幕 `y=223`。遮罩为 `#0B0E0E`：y=0–223透明，230为20%、240为60%、250为90%、255为98%、260为100%，节点间线性插值，260后保持不透明。素材本身不烘焙遮罩。
- 页面y=223对应原稿y=856.32；原稿按钮遮挡边界为y=860。两条线分别标注，均不替代核心下界800与内容避让线806。
- 轮播指示条：左距16px、顶部y=210、高3px、总长35px，当前段宽为35÷Banner数。与按钮、遮罩一起检查实际遮挡；不烘焙入素材。拖动和首尾切换时同步。
- 真实首页检查展开、滚动过渡、吸顶及回到顶部，并核对背景与阴影衔接、遮罩／按钮／指示条叠加、主题色绑定。缺少环境时记录“真实首页待验收”。旧版页面或静态叠层不能证明V2.2已完成适配。

## 内容准确与交付

- 活动主题、文字、价格、优惠、日期、商品信息及点击去向经过确认；缺少真实资料时不编造。
- 一张静态图完整表达主要信息。检查错字、伪文字、遗漏、变形、白边、透明边、拼接和背景接缝。
- 每方向交付 App 图、色号及HEX、布局、实际文案，分别记录文件技术、关键内容边界与真实首页验收状态。探索稿如实标出失败对象及坐标，等待方向反馈。
- 上线前核对活动日期、落地页、素材版本与页面主题色绑定；产品确认业务，设计检查画面，开发检查加载与绑定，测试在真实设备上验证。
