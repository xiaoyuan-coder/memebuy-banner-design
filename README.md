# Memebuy Banner Skill 使用说明

用于制作 Memebuy App 首页静态活动 Banner，输出 **1440×1000px PNG**。

## 怎么用

在 Codex 中调用 `$memebuy-banner-design`，附上：

- **业务需求**：宣传什么，希望用户点击后做什么。
- **画风参考图**：喜欢的风格；多张参考请说明对应关系。
- **文案和素材**：指定标题、按钮，以及需要使用的角色、商品或图案。没有确定文案也可以让 AI 先拟。
- **数量和偏好**：要几张，有哪些想保留或避开的元素。

可以直接这样说：

```text
使用 $memebuy-banner-design 帮我做3张首页 Banner。

业务：让用户知道可以上传喜欢的图案，制作贴纸。
标题：喜欢的图，印成贴纸。
按钮：选图打印，点击进入选图页。
画风：参考附件的毛绒材质和配色，主体重新设计。
偏好：暖色、简洁，突出标题和贴纸。
```

## 怎么修改

首轮默认出3个方向，每个方向生成一次。看图选中喜欢的方向，再说明**保留什么、修改什么**，例如：

> 选第2张。保留角色和配色，标题更醒目一些，删掉右上角装饰，按钮文字改成“立即选图”。

## 交付注意

尺寸、安全区和主题色规则已内置，无需每次重复描述。交付时会标注检查结果与待确认项，上线前仍需放入真实首页检查文字和主体是否被遮挡。

详细规则见[制作规范](references/production-rules.md)。
